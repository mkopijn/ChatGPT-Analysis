# ChatGPT Analysis

A data analysis project exploring user reviews of ChatGPT — cleaning, analyzing, and visualizing sentiment patterns to understand what users love (and dislike) about the model.

## 📁 Project Structure

| File | Description |
|------|-------------|
| `Solution.ipynb` | Jupyter Notebook with the full analysis pipeline |
| `chatgpt_reviews(1).csv` | Raw dataset of ChatGPT user reviews |
| `README.md` | Project documentation (this file) |

## 🎯 Objectives

- Clean and preprocess raw review data
- Explore rating distributions and review length trends
- Perform sentiment analysis on review text
- Identify common themes in positive vs. negative feedback
- Visualize key findings for easy interpretation

## 🛠️ Tech Stack

- **Python 3**
- **Pandas / NumPy** — data wrangling
- **Matplotlib / Seaborn** — visualization
- **NLTK / TextBlob** — sentiment analysis
- **Jupyter Notebook** — interactive environment
